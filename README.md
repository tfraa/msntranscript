## About

A Python pipeline that builds **Morphometric Similarity Networks (MSN)** from
FreeSurfer cortical data and links regional brain patterns to gene expression
(Allen Human Brain Atlas) via PLS and enrichment analysis.

Detailed documentation will be published once maintenance is complete.
